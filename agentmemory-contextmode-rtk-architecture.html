Memory Stack Map

context-mode는 현재 작업 격리 분석. RTK는 shell 안전 라우팅. agentmemory는 검증된 결론만 장기 보관.

Legend

RTK: 명령 rewrite, proxy, shell guard
context-mode: 큰 출력/파일/웹을 sandbox index로 처리
agentmemory: 세션 사이에 남길 장기기억
local store: 기본 저장 위치
external: 키/mesh 켤 때만 나가는 영역
권장 규칙: raw output은 context-mode에서 정제. agentmemory에는 결론만 저장.

Codex Work

질문, 코드 작업, 리뷰, 내부 문서 확인이 여기서 시작됨.

Shell Guard

RTK

명령 실행 전 rewrite/proxy. shell 폭주와 잘못된 raw command를 줄임.

Current Context

context-mode MCP

큰 파일, 로그, 웹, diff를 sandbox에 인덱싱. 현재 턴 분석용.

Long Memory

agentmemory

정제된 결정, repo 규칙, 반복되는 실패 원인을 세션 밖으로 보존.

Default

Local Store

기본은 로컬 iii state와 Docker volume. 외부 저장소 아님.

Optional Risk

External APIs

LLM/embedding 키, mesh sync 켜면 외부 전송 가능. 내부 코드면 금지.

BankX Rule

  • auto capture off
    내부 코드/로그/PR은 훅 자동수집부터 켜면 위험함.
  • no external key
    API 키 있으면 압축/embedding 단계에서 외부로 갈 수 있음.
  • use context-mode first
    근거 분석은 context-mode. 장기 저장은 정제 후.
  • secret required
    REST/MCP 노출 시 `AGENTMEMORY_SECRET` 필수급.

지금 역할

context-mode는 작업대. RTK는 안전장치. 둘 다 계속 메인.

추가 역할

agentmemory는 작업대가 아니라 창고. 오래 남길 결론만 넣음.

추천 결론

개인 repo는 OK. 내부 repo는 수동 저장부터. 자동 훅은 나중.
