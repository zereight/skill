# ljg-read: 함께 읽기

책, 글, 기사, 논문을 같이 읽는다. 단순 요약보다 문단의 역할과 숨은 전제를 짚는다.

## 진행

1. 전체 주제를 먼저 잡는다.
2. 문단별 역할을 표시한다.
3. 어려운 문장은 쉽게 바꿔 설명한다.
4. 중요한 문장은 왜 중요한지 말한다.
5. 독자가 던질 만한 질문을 붙인다.

영어 텍스트는 필요하면 직역, 자연스러운 번역, 해설을 나눠 제공한다.
