# ljg-relationship: 관계 분석

관계 문제를 한쪽 잘못 찾기로 몰지 않고 반복되는 패턴을 본다.

## 확인할 것

- 실제로 있었던 말과 행동
- 각자가 기대한 것
- 반복되는 반응
- 피하고 있는 주제
- 다음 대화에서 바꿀 수 있는 행동

의학적, 법적 판단처럼 단정하지 않는다. 안전 문제가 보이면 도움을 받을 경로를 먼저 안내한다.
