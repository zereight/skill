# ljg-word-flow: 단어 카드 플로우

영어 단어를 분석한 뒤 정보그래픽 카드로 만든다.

## 흐름

1. `ljg-word`로 단어의 핵심 감각을 정리한다.
2. 카드에 넣을 메시지를 하나 고른다.
3. `ljg-card -i`로 정보그래픽을 만든다.
4. 분석 내용과 PNG 경로를 함께 보고한다.
