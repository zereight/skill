# ljg-word: 영어 단어 분석

영어 단어 하나를 깊게 이해한다. 뜻 목록을 외우는 대신 이 단어가 어떤 감각으로 쓰이는지 잡는다.

## 출력

1. 핵심 감각
2. 자주 쓰는 뜻
3. 어원이나 이미지
4. 비슷한 단어와 차이
5. 예문
6. 기억할 한 문장

한국어 뜻을 여러 개 붙이고 끝내지 않는다.
