# ljg-skill-map: 스킬 지도

설치된 스킬을 훑고 어떤 일이 가능한지 지도로 정리한다.

## 실행

```bash
bash scripts/scan.sh
```

## 출력

스킬 이름, 한 줄 역할, 언제 쓰는지, 겹치는 스킬, 빠진 영역을 묶어서 보여준다.
