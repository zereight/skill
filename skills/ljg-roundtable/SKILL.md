# ljg-roundtable: 라운드테이블

하나의 주제를 여러 관점에서 토론한다. 서로 동의하는 척하지 않고 충돌하는 지점을 드러낸다.

## 역할

- 실무자: 실행 가능성을 본다.
- 회의론자: 약한 가정을 찌른다.
- 전략가: 장기 방향을 본다.
- 편집자: 논점을 정리한다.

필요하면 ASCII 표로 논점 구조를 보여준다.
