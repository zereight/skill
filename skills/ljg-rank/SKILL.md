# ljg-rank: 핵심 구조 추리기

복잡한 분야나 현상에서 정말 중요한 요인을 추린다. 목록을 많이 만드는 스킬이 아니라 줄여도 남는 구조를 찾는다.

## 진행

1. 분석 대상을 정한다.
2. 겉으로 보이는 요소를 모두 적는다.
3. 서로 겹치는 요소를 합친다.
4. 독립적으로 영향을 주는 요인만 남긴다.
5. 각 요인이 바뀌면 결과가 어떻게 달라지는지 설명한다.

최종 핵심 요인은 3~7개로 제한한다.
