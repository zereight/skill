# ljg-plain: 쉽게 풀어쓰기

어려운 글을 쉬운 한국어로 바꾼다. 내용을 줄이는 게 아니라 이해하기 쉽게 다시 쓴다.

## 원칙

- 전문용어는 필요한 만큼만 남긴다.
- 긴 문장은 나눈다.
- 추상어는 예시로 받친다.
- 원문의 주장과 범위는 바꾸지 않는다.
- 숫자, 이름, 인용은 그대로 둔다.

## 출력

쉬운 버전, 핵심 요약, 헷갈릴 수 있는 용어 설명을 제공한다.
