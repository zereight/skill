# ljg-writes: 글쓰기

생각 하나를 글로 밀고 간다. 예쁘게 포장하기보다 주장을 분명하게 세운다.

## 진행

1. 말하려는 핵심을 한 문장으로 잡는다.
2. 왜 이 주장이 필요한지 배경을 쓴다.
3. 근거를 순서대로 붙인다.
4. 반론이나 예외를 다룬다.
5. 마지막에 독자가 가져갈 판단을 남긴다.

기본은 1000~1500자다. 한국어로 자연스럽게 쓰고 번역투, 과한 접속사, 빈 수식어를 피한다.
