# ljg-think: 깊이 파고들기

주장이나 현상을 한 단계씩 파고들어 더 근본적인 질문으로 내려간다.

## 진행

1. 사용자의 문장을 그대로 받아 시작한다.
2. 핵심 주장과 숨은 전제를 분리한다.
3. 왜 그런지 계속 묻되 억지로 철학화하지 않는다.
4. 더 이상 쪼개기 어려운 지점에서 멈춘다.
5. 실무적으로 남는 판단을 정리한다.
